Hello Again is a time-looping adventure about mystical ruins, ancient secrets, and goofy weirdos. Play as a hapless ferret shipwrecked on a strange island, stuck inside a strange time loop. Explore forgotten ruins. Befriend silly strangers. Solve time-bound puzzles. Repeat for the rest of eternity.

[Play on Steam](https://store.steampowered.com/app/2052710/Hello_Again/)

# My role
Hired specifically to diagnose and resolve a critical stability issue. The diagnosis uncovered excess memory usage from oversized textures, and the resolution strengthened performance across all hardware configurations.

# Key Accomplishments
* **Crash Investigation**: Conducted deep-dive analysis to root cause persistent crashes on older hardware, documenting findings in a detailed diagnostic report.
* **Solution Framework**: Evaluated multiple resolution paths and presented trade-off analysis for informed decision-making.
* **Memory Optimization**: Solution involved reducing texture memory footprint, which resolved the crashes on legacy systems and lowered memory usage across all configurations.
